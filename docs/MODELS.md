# Выбор моделей: что брать, что не брать и почему

Статус: проверено на практике 2026-09-07 (RTX 4090 / CPU macOS), см. `docs/BUG-001-removal-quality.md` для истории багов, которые дали часть выводов.

## Детектор (боксы из текстового запроса)

| Модель | Вердикт | Почему |
|---|---|---|
| `IDEA-Research/grounding-dino-tiny` (дефолт) | ✅ брать | Лучший баланс скорость/качество из подключенных. Нашёл треки даже по кривому многословному query. ~170MB |
| `IDEA-Research/grounding-dino-base` / `-swint-ogc` | ⚠️ попробовать | Должен быть точнее tiny на мелком тексте; на 4090 разница во времени терпима. Не тестировался — проверить перед продом |
| Grounding DINO 1.5 / DINO-X (API) | ❌ | Требуют API-ключ и облако; портируемость и приватность падают |
| YOLO-World | ❌ (пока) | Порт не написан. Классы ограничены, open-vocab слабее dino для «text/logo» запросов |

## Сегментатор (боксы → маски)

В пайплайне два независимых выбора:

1. **Режим (драйвер):** `sam2` (покадрово) или `sam2-video` (пропагация по клипу).
2. **Веса (HF id):** семейство SAM2 / SAM2.1 × размер. Скачиваются на вкладке Конфиг, в форме — селект «Модель».

| Модель (HF) | Вердикт | Почему |
|---|---|---|
| `facebook/sam2-hiera-tiny` (дефолт) | ✅ брать | Быстро, хватает на оверлеи; ок на CPU |
| `facebook/sam2-hiera-small` | ✅ | Чуть точнее tiny, всё ещё лёгкий |
| `facebook/sam2-hiera-base-plus` | ⚠️ CUDA | Баланс качество/VRAM |
| `facebook/sam2-hiera-large` | ⚠️ только CUDA | Тяжёлый (~24GB VRAM по README); на простых оверлеях выигрыш мал |
| `facebook/sam2.1-hiera-tiny` | ✅ кандидат | SAM 2.1 checkpoint, тот же размерный класс |
| `facebook/sam2.1-hiera-small` | ✅ кандидат | Часто лучший старт на GPU для динамики |
| `facebook/sam2.1-hiera-base-plus` | ⚠️ CUDA | 2.1 base+ |
| `facebook/sam2.1-hiera-large` | ⚠️ только CUDA | Максимум качества / VRAM |
| режим `sam2-video` | ✅ для движения | Пропагация маски; нужен torch≥2.5 + пакет sam2. Веса те же HF id |

Важно: в transformers-режиме `Sam2Model` — видео-модель, используемая покадрово; при нескольких боксах на кадр важен порядок масок (исторический баг OR-масок починен).

## Инпейнтер (заливка)

| Модель | Вердикт | Почему |
|---|---|---|
| LaMa (`big-lama.pt`, дефолт) | ✅ CPU/CUDA | Покадровая нейро-заливка. Нет временной согласованности — на видео возможен флик |
| ProPainter (`camenduru/ProPainter`) | ✅ прод на CUDA | Видео-aware: тянет фон из соседних кадров, лучшее качество на движущемся фоне. Только GPU, память ~8-12GB VRAM на 1080p. fp16 включается автоматически |
| ProPainter на CPU | ❌ | Не заведён/неприемлемо медленно. На CPU — lama |
| Stable Diffusion inpaint | ❌ (пока) | Не подключен; генеративный fill меняет содержимое — для удаления логотипов это баг, а не фича |

## LLM-парсер (промпт → queries для детектора)

| Модель | Вердикт | Почему |
|---|---|---|
| `llava-phi3:latest` | ⚠️ с оговорками | Работает **только с `--vision-batch 2`**: на 4+ картинках выдаёт бессмыслицу. Текстовый режим слабый — нарушает контракт («remove all text» вместо `text`). Vision-режим нестабилен по kind: проверено на практике, возвращает `kind: object` с запросами-осколками (`any`, `wrong.side` — OCR с экрана) там, где ожидается `text_overlay` + `text`. В превью это видно сразу по таблице таргетов. Приемлем как дефолт, потому что дешёвый и есть у всех в ollama |
| `qwen3-vl:2b` / `qwen2.5-vl` | ✅ кандидат №1 на замену | Multi-image из коробки, лучше следует JSON-контракту. Перед продом: прогнать свои промпты, поднять `--vision-batch` до 4 |
| `llama3.2:latest` | ✅ текстовый fallback | Хорош в text-only режиме, vision нет |
| `phi4-mini`, `deepseek-r1:1.5b`, reasoning-модели | ❌ для vision-парса | Reasoning-модели заворачивают JSON в рассуждения — парс ломается; phi4-mini vision-режим не проверен |
| Облако (любая OpenAI-compatible) | ❌ не используем | Удалённые модели выключены по умолчанию: кадры видео уезжают наружу. Код ветки `--llm cloud` остался, но без ключа она не активируется |

## Правило выбора за 30 секунд

```bash
uv run videoclean doctor --device cuda   # что реально поднимется на этой машине
```

- **GPU-сервер (прод):** grounding-dino-tiny + sam2 (или sam2-video для движения) + propainter + qwen3-vl/llava-phi3 (`--vision-batch 2`)
- **Локально CPU (отладка):** grounding-dino-tiny + sam2-hiera-tiny + lama + llava-phi3
- **Никогда:** propainter на CPU, llava-phi3 с vision-batch > 2, reasoning-LLM для парса
